## 1. Vision & Strategic Positioning

### 1.1 Product Vision (1-Year Horizon)

> **"한국 직장인 100만 명이 매일 아침 출근길에 가장 먼저 켜는 앱."**
>
> Plant Buddy는 게임이 아니다. 출근이라는 무거운 일상에 작은 따뜻함을 끼워넣는 정서적 루틴 도구다. 동물의 숲의 대화 감성과 GitHub 잔디의 성취 시각화, 그리고 9시간 근무 시간이라는 직장인 고유 리듬을 결합한 유일한 카테고리.

### 1.2 Why Now? (Market Timing)

- **2025~2026 한국 직장인 정서 트렌드**: "조용한 사직(Quiet Quitting)", 번아웃, 워라밸 키워드 검색량 지속 증가.
- **모바일 힐링 게임 시장 확장**: 「놀러와요 동물의 숲」, 「Stardew Valley 모바일」, 「Alba」 등 저자극 게임 수요 증대.
- **출근 동기부여 솔루션 부재**: 「Forest」(집중 타이머)는 있지만 "출근 자체"를 보상하는 앱은 공백.
- **AI 대화 비용 하락**: v2의 AI 식물 대화 기능을 합리적 비용으로 도입 가능한 시점.

### 1.3 Differentiation Pillars

| 경쟁 카테고리 | 기존 한계 | Plant Buddy의 답 |
|---------------|-----------|------------------|
| 방치형 식물 게임 (Plant Nanny, 가지 키우기) | 24시간 접속 가능 → 의미 있는 시간 제약 없음 | **9시간 근무시간 = 게임 제약** |
| 동물의 숲 (모바일/콘솔) | 콘솔 의존, 출근 시간과 무관 | **출퇴근 시간이 곧 게임 사이클** |
| 습관 트래커 (Habitica, 챌린저스) | 강제·부담감, 정서적 보상 부재 | **식물의 "기다림"이 부드러운 동기** |
| GitHub 잔디 | 코드 커밋만 측정 | **출근이라는 가장 보편적 행위 측정** |

## 2. Discovery Analysis (Teresa Torres OST)

### 2.1 Outcome (북극성 지표)

> **"평일 출근 D7 Retention 30%"** — 평일 5일 중 4일 이상 앱을 켠 사용자 비율.

### 2.2 Opportunity Solution Tree

```
[Outcome] 평일 출근 D7 Retention 30%
│
├── [Opp1] 출근하면 무언가 나를 반긴다는 느낌
│   ├── Sol1.1: 출근 시간 기반 인삿말 (출근 푸시: "오늘도 기다리고 있었어요")
│   ├── Sol1.2: 출근 잔디 캘린더 (시각적 연속 달성)
│   └── Sol1.3: 어제 못 본 식물의 독백 표시 ("어제는 조용했네요...")
│
├── [Opp2] 9시간 동안 4번의 작은 만남이 즐겁다
│   ├── Sol2.1: 액션별 쿨다운 (현재 구현됨, 시간대별 추천 강화)
│   ├── Sol2.2: 풍부한 대화 트리 (성격별 시나리오 10개 → 30개로 확장)
│   └── Sol2.3: 점심시간/티타임 등 시간대별 특수 대화
│
├── [Opp3] 식물이 살아있다는 느낌이 강해야 한다
│   ├── Sol3.1: 성격별 말투/이모지 차별화 강화
│   ├── Sol3.2: 별명 짓기 + 별명 부르는 대화 (감정 이입)
│   ├── Sol3.3: 성장 단계별 호칭/타이틀 변화 ("작은 새싹 OO" → "용감한 OO")
│   └── Sol3.4: 날씨/계절 API 연동 → 식물 상태 변화
│
├── [Opp4] 정원이 풍성해지는 보상감
│   ├── Sol4.1: 다 키운 식물 정원 자동 배치 + 커스터마이징
│   ├── Sol4.2: 도감 100% 채우기 챌린지
│   └── Sol4.3: 시즌 한정 씨앗 (자생지 시스템)
│
└── [Opp5] 일상 생산성과 연결되는 부수 효과
    ├── Sol5.1: 씨앗 심을 때 할일 등록 → 완료 시 부스터
    ├── Sol5.2: 캘린더 연동 (구글/네이버)
    └── Sol5.3: 친구/직장동료 공유 (출근 메이트)
```

### 2.3 Top Assumptions (Impact × Risk Prioritization)

| 가정 | Impact | Risk | 검증 방법 |
|------|--------|------|-----------|
| **A1: 직장인은 "출근 동기" 자체를 갈망한다** | High | Med | 5명 인터뷰 — "출근하기 싫은 날 동기가 된 것은?" |
| **A2: 9시간 강제 루틴이 부담이 아니라 즐거움으로 작동한다** | High | High | MVP β 1주, 3일 이상 액션 4개 모두 완료한 비율 측정 |
| **A3: 풍부한 대화가 물주기보다 더 큰 retention 동인이다** | High | Med | A/B: 대화 대량 vs 미니멀 버전, D7 차이 측정 |
| **A4: 출근 잔디 시각화가 강력한 visual hook이다** | Med | Low | 베타 사용자에게 캘린더 스크린샷 공유 비율 측정 |

### 4.3 Market Sizing (TAM/SAM/SOM)

**Top-Down 방식**:
- TAM: 한국 사무직 직장인 약 1,500만 명 × 모바일 게임 사용자 비율 60% = **900만 명**
- SAM: 25~40세 사무직 직장인 약 600만 명 × 힐링게임 관심 30% = **180만 명**
- SOM (Year 1): SAM × 0.5% Early Adopter = **9,000명 MAU 목표**

**Bottom-Up 방식 (검증)**:
- 인스타/X 직장인 힐링 콘텐츠 좋아요 평균 5,000~20,000개
- 첫 6개월 SNS 마케팅으로 도달 가능 사용자 2~5만 명 → 전환율 5% = **1,000~2,500 MAU**

→ **Year 1 SOM: 5,000~9,000 MAU 보수적 목표**

## 7. Key Feature Specifications (MVP)

### 7.1 출근 시간 시스템

- **등록**: 이름(2~10자), 출근 시각(0:00~23:59), 퇴근 시각 (출근 + 9시간 자동, 수정 가능)
- **사이클**: 출근 시각이 되면 "오늘의 식물"이 시들기 시작 → 9시간 안에 액션 4회 완료해야 성장
- **퇴근 처리**: 퇴근 시각 도달 시 자동 결과 화면 → 도감/정원 등록
- **휴일 처리**: 토/일은 디폴트 휴일(설정 가능), 휴일은 잔디 색 다름(흰색)

### 7.2 대화 시스템 차별화 핵심

**"동물의 숲 수준"의 정의 (검증 가능한 기준)**:
1. **시나리오 양**: 식물당 최소 30개 이상 (현재 4 → 7배 확장)
2. **변수 삽입**: 별명/플레이어 이름/날씨/요일/시간대 변수
3. **성격 일관성**: 햇살형은 항상 느낌표, 무뚝뚝형은 항상 짧게 (감수 체크리스트)
4. **회상 대화**: 어제 한 액션을 기억해서 언급 ("어제 물 많이 줘서 뿌리가 튼튼해졌어요")
5. **선택지 분기**: 특정 선택을 자주 하면 식물 호감도 분기 → 후반 대화 분화

**대화 콘텐츠 생산 워크플로우**:
- 작가/사용자가 Google Sheet 템플릿에 입력 → JSON 빌드 스크립트로 변환 → `dialogues.js` 자동 생성
- 위 워크플로우로 콘텐츠 양산 부담 최소화

### 7.3 출근 잔디 캘린더

- **레이아웃**: GitHub 스타일 7열 × N주 / 색 단계: 0(흰색) → 1액션(연두) → 2~3액션(초록) → 4액션 + 완성(진초록)
- **공유 기능**: "이번 달 출근 기록" 이미지 다운로드 (인스타 스토리 9:16 비율 자동)
- **연속 출근 보너스**: 5일 연속 시 "주간 이펙트" 대화 + 한정 씨앗 1개 추가

### 7.4 정원

- **자동 배치**: 다 키운 식물이 정원에 자동으로 배치 (그리드)
- **회상 대화**: 정원의 식물 클릭 시 "그때 OO일 동안 함께한 OO형 해바라기" 회상 대사
- **v2 확장**: 드래그 배치, 배경 테마, 가구 (수익화 가능 지점)

### 7.5 할일(TODO) 연동 시스템 ★ MVP 핵심

> **"딴짓이 아니라 진짜 하루를 같이하는 앱"** — 할일을 해야 식물이 자란다.

**핵심 흐름**:
```
씨앗 심기(출근 등록) → 오늘의 할일 입력(1~5개)
    → 할일 완료 체크 → 식물 성장 부스터 발동
    → 퇴근 시 TODO 완료율이 결과 화면에 반영
```

**세부 스펙**:

| 항목 | 내용 |
|------|------|
| **할일 등록 시점** | 씨앗 심을 때 (SeedScreen) + 게임 중 추가 가능 |
| **할일 개수** | 최소 1개 ~ 최대 5개 (1줄 입력, 텍스트 자유) |
| **완료 체크** | GameScreen 내 TODO 패널에서 체크박스 탭 |
| **부스터 효과** | 할일 1개 완료 = 성장 게이지 +10%, 5개 완료 = 추가 대화 언락 |
| **식물 반응** | 완료 시 식물이 짧은 응원 대사 출력 ("오늘 이것까지 해냈구나! 진짜 대단해") |
| **미완료 처리** | 퇴근 시 "오늘 못 한 일이 있어도 괜찮아" 위로 대사 — 강제 없음 |
| **결과 화면** | 할일 완료 N/M 표시 + "성실한 하루" 칭찬 메시지 |
| **localStorage 키** | `pb_todos` — `[{ id, text, done, date }]` |

**직장인 특화 UX 원칙**:
1. **강제 없음**: 할일을 0개 입력해도 게임 진행 가능 (등록 권장이지 필수 아님)
2. **가벼움**: 복잡한 프로젝트 관리 X — 당일 완료 가능한 단순 텍스트만
3. **위로 우선**: 미완료 시 벌칙 대신 식물의 따뜻한 위로 대사
4. **가시성**: 게임 화면에서 할일이 식물 옆에 작게 노출 → 자연스러운 리마인드

**v1.5 확장 (SHOULD)**:
- 고정 할일 템플릿: 매주 반복되는 업무 등록 (예: "주간 보고서")
- 완료율 히스토리: 출근 잔디에 TODO 완료율 색상 레이어 추가
- 카테고리 태그: #업무 #개인 #공부 등 색상 구분

## 10. User Stories (INVEST)

### Epic A: 출근 시스템

- **A1**: 직장인으로서, 처음 앱을 켜면 30초 안에 출근 시간을 등록하고 첫 식물을 받고 싶다 — 그래야 부담 없이 시작한다.
- **A2**: 직장인으로서, 출근 시각이 되면 식물의 인삿말을 받고 싶다 — 그래야 출근 자체가 보상으로 느껴진다.
- **A3**: 야근하는 사용자로서, 출퇴근 시간을 그날 그날 조정하고 싶다 — 일정이 불규칙해도 게임이 깨지지 않게.

### Epic B: 대화 시스템

- **B1**: 사용자로서, 식물에게 별명을 지어주고 그 별명으로 불러주는 대화를 듣고 싶다 — 그래야 정이 든다.
- **B2**: 사용자로서, 같은 종류 식물도 성격에 따라 다른 말투를 쓰면 좋겠다 — 그래야 매번 새롭다.
- **B3**: 사용자로서, 어제 한 액션을 식물이 기억해주면 좋겠다 — 그래야 진짜 살아있는 느낌이 든다.

### Epic C: 잔디 & 정원

- **C1**: 사용자로서, 한 달간의 출근 기록을 잔디 그래프로 보고 싶다 — 그래야 자랑할 수 있다.
- **C2**: 사용자로서, 키운 식물을 정원에서 다시 만나보고 싶다 — 그래야 헛수고가 아니라 추억이 된다.
- **C3**: 사용자로서, 잔디 그래프 이미지를 인스타에 공유하고 싶다 — 그래야 친구도 시작하게 된다.

### Epic D: 안정성

- **D1**: 사용자로서, 한 달 모은 식물 데이터가 날아가지 않았으면 좋겠다 — 그래야 장기 사용이 가능하다.

### Epic E: 실용성 (할일 시스템)

- **E1**: 직장인으로서, 씨앗을 심을 때 오늘 해야 할 일을 3개 적고 싶다 — 그래야 앱이 단순 오락이 아니라 나의 하루를 함께하는 도구가 된다.
- **E2**: 사용자로서, 할일을 완료하면 식물이 쑥 자라는 걸 보고 싶다 — 그래야 업무 완료가 게임 보상으로 연결돼 동기가 된다.
- **E3**: 사용자로서, 할일을 다 못 끝냈어도 식물이 위로해주면 좋겠다 — 그래야 실패했을 때 앱을 끄지 않고 내일도 켜게 된다.
- **E4**: 사용자로서, 퇴근 결과 화면에서 "오늘 할일 3/4 완료!"를 보고 싶다 — 그래야 하루를 수치로 돌아볼 수 있다.
- **E5**: 야근하는 사용자로서, 할일이 없는 날에는 그냥 빈 칸으로 두고 싶다 — 강제로 입력하게 하지 않았으면 좋겠다.
