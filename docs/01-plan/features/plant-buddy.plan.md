## Executive Summary

| Perspective | Summary |
|-------------|---------|
| **Problem** | 현재 물주기·햇빛·쓰다듬기·대화 4액션은 고민 없이 만들어진 구조라 식물별 개성이 없고, 아무 액션이나 반복해도 되는 단순 클릭 게임에 그친다. |
| **Solution** | 식물마다 고유한 액션 프로파일(필수/금지/선호)을 부여하고, 과잉 액션 패널티·비료 아이템·미완성 식물 처리를 설계해 "어떻게 키우느냐"가 의미 있는 게임으로 만든다. |
| **Function/UX Effect** | 선인장에 물을 3번 주면 경고가 뜨고 love가 깎인다. 딸기는 물을 좋아해서 많이 줘도 괜찮다. TODO를 완료하면 비료를 얻어 위기 상황에 쓸 수 있다. 퇴근 시 못 키운 식물도 성장 정도에 따라 다르게 처리한다. |
| **Core Value** | "식물마다 다르게 키워야 한다"는 학습 곡선이 반복 플레이의 동기가 되고, 정원이 다양한 식물로 채워질수록 유저의 성취감이 깊어진다. |

## Context Anchor

| Key | Value |
|-----|-------|
| **WHY** | 1일 1식물 루틴 게임의 핵심 재미는 "오늘 이 식물을 어떻게 키울까"라는 전략적 선택. 지금은 그 선택이 없다. |
| **WHO** | 25~40세 한국 사무직 직장인 — 9시간 근무 중 4~5번 앱을 켜는 사람 |
| **RISK** | (1) 밸런스가 너무 어려우면 포기, 너무 쉬우면 무의미 (2) 식물별 프로파일이 직관적이지 않으면 유저가 규칙을 학습 못 함 |
| **SUCCESS** | (1) 식물마다 다른 전략이 필요하다는 걸 첫 2종 플레이 후 유저가 인지 (2) 퇴근 결과 화면에서 "완성" 비율 60% 이상 (너무 어렵지 않게) |

## 1. 액션 시스템 (Action System)

### 1.1 4가지 기본 액션

| 액션 | 아이콘 | 기본 쿨타임 | 설명 |
|------|--------|------------|------|
| 물주기 (water) | 💧 | 2시간 | 수분 공급 — 식물마다 선호량 다름 |
| 햇빛 (sun) | ☀️ | 2시간 | 광합성 — 실내/실외 식물 차이 |
| 쓰다듬기 (pet) | 🤲 | 2시간 | 정서적 교감 — 허브류 선호 |
| 대화 (talk) | 💬 | 2시간 | 언어적 자극 — 나무류 선호 |

**1일 9시간 기준 최대 사용 횟수**: 액션당 최대 4회 (0h·2h·4h·6h), 현실적으로 3회 기준 설계

### 1.2 5번째 액션 — 비료 (fertilizer) ★아이템

- **획득 방법**: TODO 완료 시 1개 지급 (상세는 §3)
- **최대 보유**: 3개
- **쿨타임**: 없음 (아이템 소모)
- **효과**: 즉시 love +20, 사용 시 식물이 기쁜 반응 대사 출력
- **전략적 가치**: 액션을 못 했거나 페널티로 love가 깎였을 때 회복 수단

## 2. 식물별 액션 프로파일 (Per-Plant Profiles)

### 2.1 프로파일 구조

각 식물은 4액션에 대해 다음을 정의한다:

```
{
  min: 하루 최소 권장 횟수 (미달 시 성장 패널티)
  safe_max: 패널티 없이 사용 가능한 최대 횟수
  penalty_start: 이 횟수 초과부터 경고 표시 (love 감소 없음)
  penalty_hard: 이 횟수 초과부터 love 실제 감소
  is_favorite: true면 보너스 love 지급
}
```

### 2.2 식물별 프로파일 정의

#### 해바라기 (difficulty: 1 — 입문)
> "햇빛을 많이 줄수록 빠르게 자라요." — 햇빛을 아무리 줘도 OK, 물은 중간

| 액션 | min | safe_max | penalty_start | penalty_hard | favorite |
|------|-----|----------|--------------|--------------|---------|
| water | 1 | 3 | 4 | 5 | N |
| sun | 1 | 무제한 | — | — | **Y** |
| pet | 0 | 3 | 4 | 5 | N |
| talk | 0 | 3 | 4 | 5 | N |

#### 선인장 (difficulty: 1 — 입문, 트릭 있음)
> "물을 적게, 햇빛을 많이 주세요." — 물 2번째부터 경고, 3번째부터 love 감소

| 액션 | min | safe_max | penalty_start | penalty_hard | favorite |
|------|-----|----------|--------------|--------------|---------|
| water | 0 | **1** | **2** | **3** | N |
| sun | 2 | 무제한 | — | — | **Y** |

## 3. Love 점수 & 성장 알고리즘

### 3.1 Love 획득 공식

```
기본 액션 love = 10
favorite 액션 = 10 + 5 (보너스) = 15
min 달성 보너스 = 행동당 +3 (하루 종료 시 정산)
비료 사용 = +20

페널티 (penalty_start 초과 시, 경고만):
  → love 변화 없음, 식물 경고 대사 표시

페널티 (penalty_hard 초과 시, 실제 감소):
  → 초과 횟수당 -15 love
  → 연속 초과 시 -15 → -20 → -25 (누적)

min 미달 패널티 (하루 종료 시 정산):
  → 미달 액션당 -10 love
```

### 3.2 단계별 love 요구량 (6단계)

| 단계 | 이름 | 누적 love 필요량 | 달성 난이도 |
|------|------|-----------------|------------|
| 0→1 | 씨앗 → 발아 | 20 | 액션 2회면 OK |
| 1→2 | 발아 → 성장 | 45 | 4~5회 |
| 2→3 | 성장 → 중간 | 75 | 7~8회 |
| 3→4 | 중간 → 후반 | 110 | 10~11회 |
| 4→5 | 후반 → 완성 | 150 | 13~14회 (비료 없이 한계) |

**1일 이상적 max love 계산 (페널티 없이)**:
- 3회 × 4액션 × 10 love = 120
- favorite 보너스: +5 × 3 = +15
- min 달성 보너스: 액션당 +3 × (충족된 min 개수)
- **현실적 max ≈ 145 love** → 비료 1개면 완성 가능, 비료 없이 완성하려면 거의 완벽해야

### 3.3 결과 판정 기준 (퇴근 시)

| 누적 love | 판정 | 결과 |
|----------|------|------|
| ≥ 150 | 완성 ★★★ | 정원 입성 + 도감 등록 + 완성 대사 |
| 110~149 | 아쉬운 성공 ★★☆ | 정원 입성 (4~5단계 상태) + 특별 대사 |
| 60~109 | 부분 성장 ★☆☆ | §4 미완성 처리 참고 |
| < 60 | 거의 실패 | §4 미완성 처리 참고 |

## 4. 미완성 식물 처리 (Failed Plant Handling)

> **핵심 원칙**: 실패해도 "아무 의미 없다"는 느낌을 주지 않는다. 식물이 완전히 사라지면 유저의 하루가 무의미해진다.

### 4.1 처리 방식 (love 기준)

#### love 110~149 (아쉬운 성공)
- 정원에 **4단계 상태**로 배치됨
- "조금만 더 했으면 완성이었는데..." 식물 대사
- 도감에 별도 표시: "(미완성)" — 나중에 완성 버전과 구분

#### love 60~109 (부분 성장)
- 정원에 **3단계 상태**로 배치됨 (분명히 자란 흔적)
- "오늘은 힘들었구나. 그래도 잘 버텼어." 위로 대사
- **조각 씨앗 0.5개** 보상: 나중에 같은 식물을 키울 때 시작 love +15 부스터

#### love < 60 (거의 실패)
- 정원에 배치되지 않음 (식물은 시들어 사라짐)
- **씨앗 반환**: 같은 종류 씨앗을 0.5개 되돌려 받음 (씨앗 인벤토리에 분수 표시 → 2번 모이면 1개)
- 식물의 마지막 대사 (가장 진심이 담긴 대사)
- "미완성 도감" 항목: 시도한 식물·날짜·이유 기록 (성취감 대신 기록으로)

### 4.2 미완성 도감 (Unfinished Dex)

기존 도감 화면에 **"미완성 기록" 탭** 추가:
- 아이콘: 반쯤 자란 식물 (흐린 색)
- 정보: 식물명, 날짜, 달성한 단계, 주요 실수 (예: "물을 4번 줬어요")
- 같은 식물을 다시 키울 때 "지난번엔 여기서 막혔었지" 특별 대사 트리거

## 5. 패널티 UI — 유저가 알 수 있도록

> "유저가 알 수 있도록 해야 한다" — 페널티가 조용히 작동하면 안 됨.

### 5.1 액션 버튼 상태 표시

```
[물주기 💧] (1/3) ← 오늘 사용 횟수 / safe_max
[물주기 💧] ⚠️(2/3) ← penalty_start 도달, 경고색
[물주기 💧] ❌(3/3) ← penalty_hard 도달, 비활성화 색
```

- safe 범위: 버튼 정상 색
- penalty_start 도달: 버튼 노란색 테두리 + ⚠️ 아이콘
- penalty_hard 도달: 버튼 빨간색 + ❌

### 5.2 페널티 발생 시 피드백

1. **식물 대사** (penalty_start): "잠깐... 좀 많이 주는 것 같지 않아?"
2. **식물 대사** (penalty_hard): "이러다가 나 힘들어질 것 같아 ㅠ" + love -15 알림
3. **화면 이펙트**: 식물이 살짝 흔들리는 애니메이션
4. **love 변화 알림**: "-15 💔" 텍스트가 식물 위에서 떠오르고 사라짐

### 5.3 min 미달 경고 (하루 중간)

- 퇴근 2시간 전: "오늘 [액션명]을 아직 한 번도 안 했어요" 알림 (알림 아님, 게임 화면 내 인디케이터)
- min이 필요한 식물인 경우에만 표시

## 6. 비료 시스템 상세 (Fertilizer)

### 6.1 획득 경로

- TODO 1개 완료 → 비료 1개 지급
- 최대 보유: 3개 (넘치면 "오늘은 충분해요" 대사)
- 당일 미사용 비료는 다음날 이월 (보유량 유지)

### 6.2 TODO 시스템 연동 흐름 (확정)

```
[SeedScreen] 씨앗 심기
    → 오늘 할일 초기 입력 (0~5개, 선택)

[GameScreen] 플레이 중
    → 하단에서 위로 슬라이드업 → TODO 패널 열림
    → 할일 완료 체크 ✓ → 비료 +1 즉시 지급
    → 할일 추가/수정 가능 (하루 중 언제든지)
    → 비료 버튼: TODO 패널 상단에 배치 (보유 개수 배지)
    → 비료 사용 시 확인 없이 즉시 적용 → love +20
```

### 6.3 UI 배치

- **TODO 패널**: GameScreen 하단 슬라이드업 (평소엔 탭 핸들만 보임)
- **비료 버튼**: TODO 패널 상단 우측 (개수 배지 표시, 0개면 회색)
- **완료 체크**: 각 TODO 항목 좌측 체크박스, 완료 시 취소선 + 비료 획득 토스트

### 6.3 비료 사용 피드백

- 식물이 폭풍 성장하는 짧은 애니메이션
- love +20 알림 "+20 🌿"
- 식물 대사: "이게 뭐야... 엄청난데?!" (식물 성격별 반응 다름)

## 7. 데이터 모델 변경

### 7.1 plants.js — actionProfile 필드 추가

```js
// 기존 favoriteAction 유지하면서 actionProfile 추가
{
  id: 'cactus',
  favoriteAction: 'sun', // 기존 (하위 호환)
  actionProfile: {
    water: { min: 0, safeMax: 1, penaltyStart: 2, penaltyHard: 3 },
    sun:   { min: 2, safeMax: Infinity, penaltyStart: Infinity, penaltyHard: Infinity },
    pet:   { min: 0, safeMax: 3, penaltyStart: 4, penaltyHard: 5 },
    talk:  { min: 0, safeMax: 3, penaltyStart: 4, penaltyHard: 5 },
  }
}
```

### 7.2 storage.js — 새 키

| 키 | 타입 | 내용 |
|----|------|------|
| `pb_gamestate` | Object | 기존 + `actionCounts: {water,sun,pet,talk}` + `penalties: {water,...}` |
| `pb_fertilizers` | Number | 보유 비료 개수 (0~3) |
| `pb_unfinished` | Array | 미완성 식물 기록 `[{plantId, date, finalStage, finalLove, mainMistake}]` |

### 7.3 GameScreen — 상태 변경

```js
// 기존 totalActions → 액션별 카운트로 교체
const actionCountsRef = useRef({ water: 0, sun: 0, pet: 0, talk: 0 })
const penaltiesRef = useRef({ water: 0, sun: 0, pet: 0, talk: 0 })

// 기존 love 계산 로직 교체
function calcLoveGain(actionType, plant) {
  const profile = plant.actionProfile[actionType]
  const count = actionCountsRef.current[actionType]
  if (count >= profile.penaltyHard) return -15 - (count - profile.penaltyHard) * 5
  if (count >= profile.penaltyStart) return 0 // 경고만, love 변화 없음
  const base = 10
  const bonus = plant.favoriteAction === actionType ? 5 : 0
  return base + bonus
}
```

## 8. 정원 시스템 (Garden System)

> **그래픽 방향에 따라 배치 방식이 달라지므로 핵심 원칙만 정의. 상세 UI는 별도 Design 단계에서 확정.**

### 8.1 정원 원칙

### 13.1 동물 친구 시스템 🐾 (유저 제안)

**컨셉**: 정원이 풍성해질수록 동물들이 놀러오기 시작한다.

```
[정원 식물 3개 이상] → 가끔 동물 친구가 방문
    저벅저벅 걸어와서 잠깐 머뭄
    → 상호작용 (먹이주기, 쓰다듬기)
    → 친밀도 게이지 누적
    → 친밀도 MAX → "정원에 살고 싶어요" 이벤트
    → 수락 → 정원 주민 등록 (항상 정원에 있음)
```

**동물 아이디어**:
- 고슴도치 — 수줍음 많음, 자주 안 옴, 오면 공 모양으로 웅크림
- 달팽이 — 엄청 느림, 식물 잎 위에서 낮잠
- 새 — 아침에만 옴, 지저귀고 씨앗 하나 두고 감 (희귀 씨앗 획득)
- 고양이 — 규칙 없이 옴, 식물 옆에서 꾹꾹이
- 개구리 — 비 오는 날에만 등장 (날씨 API 연동 시)

**친밀도 시스템**:
- 상호작용마다 친밀도 +1
- 동물마다 성격/말투 있음 (식물 대화 시스템과 동일한 구조 활용)
- 친밀도 단계별 대사 변화

### 13.2 식물들의 수다 🌿💬 (추가 아이디어)

**컨셉**: 정원에 식물이 여러 개 모이면, 유저 몰래 식물들끼리 대화하는 장면이 가끔 등장.

```
정원 화면에서 잠시 기다리면...
"어제 나한테 물 세 번이나 줬잖아 ㅠ" (라벤더)
"나도 들었어... 많이 당황했겠다" (해바라기)
"그래도 비료 줬을 때는 진짜 행복했어" (라벤더)
```

- 완전히 랜덤한 배경 이벤트 — 유저가 방해하면 멈춤
- 식물 조합마다 다른 대화 (해바라기+선인장, 벚나무+라벤더 등)
- 수다 내용에 유저 플레이 기록이 반영됨 ("어제 그분이...")

### 13.3 식물 편지 ✉️ (추가 아이디어)

**컨셉**: 정원의 식물이 가끔 편지를 남긴다. 유저가 없는 동안 일어난 일을 전달하는 방식.

- 오랫동안 접속 안 했을 때: "보고 싶었어. 오늘 하늘이 맑아서 네 생각이 났어"
- 새 씨앗 심는 날: "새 친구가 오는 거야? 잘 맞았으면 좋겠다"
- 동물 친구가 다녀갔을 때: "오늘 귀여운 고슴도치가 왔다 갔어. 너 보고 싶어하던 것 같았어"
- 편지 보관함: 받은 편지를 모아두는 컬렉션 (도감처럼)

### 13.4 계절 이벤트 🌸❄️ (추가 아이디어)

**컨셉**: 실제 날짜 기반으로 정원 분위기가 변한다.

| 계절 | 이벤트 |
|------|--------|
| 봄 (3~5월) | 벚꽃 잎이 정원에 날림, 봄 한정 씨앗 |
| 여름 (6~8월) | 물뿌리개 쿨타임 단축 (더워서 더 자주), 선인장 꽃 희귀 이벤트 |
| 가을 (9~11월) | 낙엽이 정원에 쌓임 → 치우기 미니액션, 단풍 한정 씨앗 |
| 겨울 (12~2월) | 눈 내림, 식물에 이불 덮어주기 액션, 분재 특별 이벤트 |

### 13.5 씨앗 교환 엽서 📮 (추가 아이디어)

**컨셉**: 친구와 씨앗 교환 — 비동기식, 직접 연결 없이 코드로.

### 14.2 지각 페널티 — 타이머 동기화

```
→ 게임 경과 시간이 처음부터 30:00으로 시작
→ 퇴근 시간(18:00)까지 남은 시간도 30분 줄어든 상태
```

유저 피드백: 접속 시 "오늘 30분 늦었어요. 조금 바빠질 것 같아요! 🌿" 메시지 표시.

### 14.3 야근 시스템 (A안 — 효율 감소)

**원칙**: 야근을 허용하되, 정규 시간 대비 love 획득 효율을 낮춰 과도한 연장의 메리트를 줄인다.

| 근무 상태 | love 획득 효율 | 근거 |
|----------|--------------|------|
| 정규 근무 중 | 100% (+10 기본) | 집중력 정상 |
| 야근 중 | 70% (+7 기본) | "피곤해서 집중력이 낮아요" |

**야근 선언 흐름**:
```
퇴근 30분 전 → GameScreen 상단에 배너 노출
  "오늘 퇴근 시간이 30분 남았어요. 연장 근무 할까요?"
  [오늘 퇴근] / [1시간 연장] / [2시간 연장]

→ 연장 선택 시:
  - todayEnd 갱신
  - isOvertime = true 플래그 저장
  - 이후 doAction() 에서 야근 여부 확인 → love × 0.7
```

**남용 방지**: 쿨타임(실서비스 기준 1~2시간/액션) + safeMax가 실질적 상한. 야근으로 추가 얻을 수 있는 love는 쿨타임 1사이클분(최대 +40 정도)에 불과해 효율 감소 없이도 큰 이득이 없으나, A안은 심리적 "정직한 플레이" 유도 효과.

```js
// 세션 시작 시각 계산 (지각 반영)
function calcSessionStart(todayStart) {
  const now = Date.now()
  const commuteMs = timeStrToMs(todayStart) // '09:00' → ms
  const todayMs = getTodayBaseMs()           // 오늘 00:00 ms
  const commuteTimestamp = todayMs + commuteMs
  return Math.min(now, commuteTimestamp)     // 지각이면 출근 시각으로 당겨서 시작
}

// 야근 여부에 따른 love 배율
function getLoveMultiplier(todayEnd, isOvertime) {
  if (!isOvertime) return 1.0
  return 0.7
}
```
